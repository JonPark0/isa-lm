## Cephes Math Library

The SIMD `exp` approximations (`kernels/x86_common.h`, `kernels/x86_avx.h`,
`kernels/arm_common.h`) use the range reduction and polynomial coefficients of
`expf` from the Cephes Math Library by Stephen L. Moshier.

## Unicode Character Database

`model/unicode_tables.c` is generated by `tools/gen_unicode.py` from the
letter and number categories of the Unicode Character Database, as shipped
with Python's `unicodedata` module. Unicode data is provided under the
[Unicode License v3](https://www.unicode.org/license.txt).

## Hugging Face tokenizers

`tests/data/spm_tiny.json` and `tests/data/bpe_tiny.json` were trained for the
tests with the [tokenizers](https://github.com/huggingface/tokenizers) library
(Apache License 2.0) on text written for this project. The Llama 3
pre-tokenizer pattern matched by `model/bpe.c` is the one published in Meta's
Llama 3 `tokenizer.json`.
